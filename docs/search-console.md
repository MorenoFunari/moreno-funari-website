# Google Search Console

## Proprietà

```text
Tipo: Proprietà Dominio
Dominio: morenofunari.it
Metodo di verifica: record TXT DNS
Provider DNS: Porkbun
```

Il valore reale del record TXT di verifica non deve essere conservato nel repository.

## Sitemap

```text
https://morenofunari.it/sitemap.xml
```

La sitemap deve essere inviata dal report Sitemap della proprietà Google Search Console.

## URL prioritari

```text
https://morenofunari.it/
https://morenofunari.it/blog
https://morenofunari.it/blog/la-fiducia-arriva-dopo-il-primo-passo
https://morenofunari.it/coaching
https://morenofunari.it/ebook
```

Questi URL possono essere controllati con lo strumento Controllo URL.

## URL intenzionalmente non indicizzabili

```text
https://morenofunari.it/privacy-policy
https://morenofunari.it/cookie-policy
https://morenofunari.it/documents/un-passo-possibile-moreno-funari.pdf
```

Le pagine legali usano meta robots `noindex, follow`. Il PDF usa l'header `X-Robots-Tag: noindex, follow`. Queste esclusioni sono intenzionali.

## Sottodominio app

La proprietà Dominio comprende anche:

```text
app.morenofunari.it
```

Le pagine dell'app configurate come `noindex` possono apparire nei report come escluse intenzionalmente.
